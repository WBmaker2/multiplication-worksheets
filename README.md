# 몽실몽실 초등 2학년 두 자릿수 곱셈 세로셈 연습장 🌸

초등학교 2학년 학생들을 위한 **‘두 자릿수 × 한 자릿수 곱셈’** 세로셈 연습 웹 애플리케이션입니다.

## ✨ 주요 기능
- **세로셈 단계별 풀이 제공**:
  ```text
     19
   ×  3
  ------
    27  (일의 자리 곱: 9 × 3)
    30  (십의 자리 곱: 10 × 3)
  ------
    57  (최종 합산)
  ```
- **총 5페이지 구성**: 1쪽당 9문제 (총 45문제) 단계별 난이도 학습
- **자동 채점 및 피드백**: 맞춘 개수 및 칭찬 배너 제공
- **정답지 뷰**: 전체 5페이지의 모든 정답 및 풀이 과정 확인 가능
- **새 문제 생성**: 무한으로 새로운 랜덤 문제 생성
- **A4 학습지 인쇄 지원**: 깔끔한 종이 학습지 양식으로 바로 출력 가능
